# RoMarket Staff Handbook

This repository holds the source code for RoMarket's Staff Handbook.

### Informatiom
When updating the handbook, please ensure to follow the style guide below to ensure consistencies.

### Style Guide
1. All Page Titles in .mdx files should use '#'.  
2. All Subtitles in .mdx files should use '###'.  
3. If you require smaller headings, use '####'.  
4. All Headings should use `<font color="#Colour">Heading</font>`.  
5. All Pages should have a `:::info` message under the title detailing what the page is about.
6. Ensure there is consistency between the colour and branding across pages.

If you are unsure about syntax for .mdx files, [read this document](https://docusaurus.io/docs/markdown-features).

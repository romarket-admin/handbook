# Punsishment Guide

:::info[Info]
This page details the punishments for each rank at RoMarket.
:::

### Information

- Please ensure that you have proper evidence for every punishment.   
- For Blacklist or Permanant Bans, please make a Human Resources Ticket in the [Support Channel](https://discord.com/channels/1456118310860095651/1456438503519813789).  
- Not all punishments are listed below. Use common sense, abusing loopholes will not be tolerated.   
- Only SHRs are allowed to provide a different punishment than listed below.
- If a player has been demoted 3 times, they can be blacklisted. Please create a ticket if this is the case.

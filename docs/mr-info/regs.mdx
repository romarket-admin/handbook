# Regulations

:::info[Info]
This page details all the regulations that Middle Rank Staff Members at RoMarket must follow.
:::

### Uniform

Middle Rank Staff Members must choose out of the following for in game uniform:   
- RoMarket Staff T-Shirt
- RoMarket Staff Jumper
- RoMarket Security Vest (only with Security Gamepass)
- Any item in the Group Store marked [U]


### Working
Middle Rank Staff Members are only allowed to do the following things whilst on duty:
- Restock Shelves
- Clear Rubbish Bins
- Clean Spills
- Arrest Shoplifters (Security Only)
- Work at Departments
- Help Customers



### In Game Punishments

- Middle Rank Staff Members must not do any of the following listed below.   
- The list is not exhaustive, loopholes will not be tolerated.   
- Members of the SHR Team are allowed to change the punishment as deemed suitable.
